# Truco do Mateus (Android)
Aplicativo Android offline: jogo em dupla contra bots, incorporado localmente no APK (sem conteúdo remoto). Truco paulista simplificado, partida até 15.

Build APK remoto: `eas build --platform android --profile preview`.

Observação: regras são uma proposta simplificada; não contempla sinais, mão de onze, sequência completa de aumentos nem variantes regionais.
